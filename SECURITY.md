# Security

Please do not report security vulnerabilities in public issues or pull
requests. Use GitHub's private vulnerability reporting on this repository's
Security tab if available. If it is not enabled, contact the repository
maintainer privately through GitHub before sharing details.

Include the affected version, a description of the impact, and reproducible
steps using fictional data. Never include real credentials or employee data.

See [deployment configuration](DEPLOYMENT_CONFIGURATION.md) for security
requirements and current operational limitations.
